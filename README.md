# CommonChange Frontend
=======================

## Overview

This is the frontend application for the CommonChange platform, built using React, TypeScript, and Tailwind CSS.

## Getting Started

### Prerequisites

* Node.js (version 14 or higher)
* npm (version 6 or higher)
* Vite (version 4 or higher)

### Installation

1. Clone the repository: `git clone https://github.com/your-username/act-of-sharing-frontend.git`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`

### Build and Deployment

1. Build the application: `npm run build`
2. Deploy the application to a cloud platform such as Vercel or Netlify.

## Features

* User authentication and authorization
* Event creation and management
* Contribution management
* Messaging system
* Responsive design using Tailwind CSS

## Technologies Used

* React (version 18)
* TypeScript (version 5)
* Tailwind CSS (version 3)
* Vite (version 4)
* React Router (version 6)
* React Icons (version 5)
* Stripe (version 3)

The API documentation is generated using Swagger and can be found at `http://localhost:3000/api-docs`.
